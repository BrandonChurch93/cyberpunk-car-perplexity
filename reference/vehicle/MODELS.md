# Mesh and license check

Build the hero vehicle procedurally. The strongest full-car candidate is a downloadable CC Attribution listing with a clear self-authorship claim, but I did not find a build record or enough supporting evidence to clear it at this project's strict threshold. No model files were downloaded. A license badge and a triangle count do not verify authorship, accurate scale or suitability for macro shots.
