# Rooftop

A short film for X: a supercar on a rooftop car park at night, in heavy rain, in a neon city. Built in code and rendered frame by frame.

- The deliverable is the video. The app in this repo exists to produce it.
- `AGENTS.md` holds the rules for the agent that builds it.
- `kit/` holds the full specification. Start at `kit/00-README.md`.
- `config/showcase.json` holds every number.
- `kit/PROGRESS.md` is the build log.
- `kit/10-KICKOFF.md` has the prompts that start and resume the build.

The Builder replaces this file at the end of the build with the app URL, how to run it and how to export.
